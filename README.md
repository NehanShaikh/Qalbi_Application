# Qalbi

**Qalbi (قلبي)** is an Islamic companion app built with Flutter, bringing Quran, Hadith, Dhikr, Dua, Tasbih, Qibla, and Islamic calendar features together in one application.

## 📥 Downloads

The latest release provides builds for Android and Windows.

| Platform | Download |
|---|---|
| 📱 Android | `Qalbi.apk` |
| 🖥️ Windows | `Qalbi-Windows.zip` |

Go to the **Releases** section of this repository to download the latest version.

## ✨ Features

### 📖 Quran

- Complete 114 Surahs
- Arabic Quran text
- IndoPak Arabic text support
- English translation
- Transliteration
- Juz / Para reader
- Quran search
- Adjustable Arabic text settings
- Adjustable reading settings
- Dark and light themes
- Offline Quran reading

### 🔖 Quran Reading Tools

- Bookmarks
- Personal notes
- Last Read
- Exact Ayah navigation
- Continue Reading from the Home screen

### 🎧 Quran Audio

- Complete Surah playback
- Juz / Para playback
- Ayah playback
- Multiple Quran reciters
- Play, pause, seek, rewind and fast-forward
- Previous / next controls
- Background playback
- Lock-screen media controls
- Android media notification
- Audio downloads and caching

### 📚 Hadith

- Sahih al-Bukhari
- Sahih Muslim
- Sunan Abu Dawud
- Jami' at-Tirmidhi
- Sunan an-Nasa'i
- Sunan Ibn Majah
- Arabic Hadith text
- Hadith bookmarks
- Hadith Last Read

### 🤲 Dhikr & Dua

- Dua categories
- Arabic Dua text
- Translation
- Dhikr
- Search
- Bookmarks
- Offline access

### 📿 Tasbih

- Digital Tasbih counter
- SubhanAllah
- Alhamdulillah
- Allahu Akbar
- La ilaha illallah
- Custom counting

### 🧭 Qibla

- Qibla direction using the device compass
- Location-based Qibla calculation
- Qibla alignment indicator
- Beep when aligned with the Qibla

### 📅 Islamic Calendar

- Islamic / Hijri date
- Gregorian date
- Islamic calendar information

### 🎨 Settings

- Light / Dark / System theme
- Arabic font selection
- Arabic text size controls
- Translation visibility
- Transliteration visibility
- Persistent reading preferences

## 🚀 Installation

### Android

1. Open the **Releases** section.
2. Download `Qalbi.apk`.
3. Transfer the APK to your Android device if necessary.
4. Install the APK.
5. If required, allow installation from unknown sources in your Android settings.

### Windows

1. Open the **Releases** section.
2. Download `Qalbi-Windows.zip`.
3. Extract the ZIP file.
4. Open the extracted folder.
5. Run `Qalbi.exe`.

**Important:** Keep the Windows files together inside the extracted folder. Do not move `Qalbi.exe` separately.
